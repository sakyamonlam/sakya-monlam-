SAKYA MONLAM — VERSION 1

This is a first mobile-friendly web-app prototype.

How to use:
1. Open index.html in Safari or Chrome.
2. On iPhone/iPad: Share -> Add to Home Screen.
3. On Android: browser menu -> Add to Home screen / Install.

Version 1 includes:
- Home screen
- 35th Sakya Monlam event banner
- Prayers, Events, Live and Donate sections (visual placeholders)
- Latest update
- About section
- Mobile navigation

Next version can add real pages, Tibetan/English language switching, donation/UPI, live YouTube stream, admin updates, push notifications, member login, and Android/iOS packaging.
